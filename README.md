# StudyPath 📚
> Your path. Your pace. Your progress.

Plataforma web de gestão de estudos desenvolvida com HTML, CSS e JavaScript puro. Permite cadastrar disciplinas, acompanhar progresso em tempo real, definir desafios e organizar a agenda de estudos.

## 🚀 Funcionalidades
- Dashboard animado com barras de progresso por disciplina
- Alertas inteligentes de desempenho
- Cadastro de disciplinas com notas e status automático
- Sistema de desafios e metas pessoais
- Agenda com lembretes personalizados
- Dados salvos localmente via localStorage

## 🛠 Tecnologias
- HTML5
- CSS3
- JavaScript ES6+
- localStorage API
